\declaredin{BPatch\_sourceObj.h}

\code{BPatch\_sourceObj} is the base class for
\code{BPatch\_function}, \code{BPatch\_module}, and \code{BPatch\_image}.
It provides a set of common methods for all three classes. In
addition, it can be used to build a ``generic'' source
navigator using the getObjParent and getSourceObj methods to get
parents and children of a given level (i.e. the parent
of a module is an image, and the children will be the functions).

\begin{apient}
  bool getSourceObj(std::vector<BPatch_sourceObj*>& objs);
\end{apient}

\apidesc{
  Returns the child source objects of the current source object, one level
  down: called on a \code{BPatch\_image} it returns that program's modules,
  and called on a \code{BPatch\_module} it returns that module's functions.
  Returns \code{true} on success and \code{false} on error.

  \code{BPatch\_function} does not implement this. It clears \code{objs} and
  returns \code{false}, so the loops and statements within a function cannot
  be reached this way.
}

\end{apient}

\apidesc{
  Return the parent source object of the current source object. The
  parent of a \code{BPatch\_\-image} is \code{nullptr}.
}
